## 4. Правило добавления новых документов

1. Новый документ получает следующий свободный номер (DOC-030 и далее); существующие номера не переиспользуются и не перенумеровываются.
2. Документ создаётся по формату паспорта (см. DOC-029).
3. Обновляются: `DOCUMENTATION_MAP.md` (дерево + таблица + группа) и `documentation.manifest.json`.
4. Если новый документ становится источником истины для домена — обновляется таблица в `INDEX.md`.
