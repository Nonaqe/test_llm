# Руководство администратора

## Краткое содержание

- Первый вход (визард).
- Проекты и сайты.
- Подключение AI.
- Знания и настройка ниши.
- Тестирование бота.
- Команда и настройки.

Сценарии зафиксированы; точный вид экранов — TBD до реализации UI.

## 1. Первый вход (визард)

1. После установки (DOC-016) откройте `https://chat.example.com` — запустится визард.
2. Введите **одноразовый SETUP-токен** (напечатан installer'ом в консоли).
3. Создайте администратора (email + пароль).
4. Визард проведёт по шагам: создать проект → сайт → подключить AI → загрузить знания → настроить ассистента → получить сниппет. Каждый шаг можно пропустить и вернуться позже.

## 2. Проекты и сайты

**Проект** — изолированное пространство: свои сайты, ассистент, знания, операторы. Создайте проект на компанию/направление.

**Сайт** (Проект → Сайты → Добавить):

1. Название и домен (например `site-a.com`).
2. Allowed origins: домены, с которых разрешён виджет (включая `https://`; для локальной отладки добавьте `http://localhost:3000`).
3. Виджет: цвет, логотип, положение, приветствие, тексты, язык, свой CSS (DOC-008 §4).
4. Сохраните → скопируйте **сниппет** («Сниппет для установки») и **публичный ключ**.

Установка сниппета на сайт — DOC-024; для WordPress — DOC-009. Регенерация ключа (при компрометации) — кнопка на карточке сайта.

## 3. Подключение AI

Настройки → AI-провайдер:

1. Выберите пресет (OpenAI / DeepSeek / OpenRouter / свой endpoint / **Local (Ollama)**).
2. Введите Base URL и **API-ключ** (ключ шифруется; маскируется в UI).
3. Модели: chat-модель и embedding-модель (дефолты подходят для старта).
4. «Проверить соединение» — тестовый вызов.

Важно: ключ — ваш собственный, оплата счёта провайдера на вашей стороне (BYOK). Смена embedding-модели запускает переиндексацию знаний (займёт время).

## 4. Знания и настройка ниши

**Загрузка документов** (Проект → Знания): перетащите PDF/DOCX/TXT/CSV/MD или добавьте URL/FAQ/текст. Следите за статусами: `indexing → ready`; `failed` — с причиной (частая: PDF-скан без текстового слоя).

**Настройка ниши** (Проект → AI-ассистент) — без программирования:

| Поле | Пример (клиника) |
|---|---|
| Название | «Помощник клиники» |
| Язык / Тон | Русский / Профессиональный |
| Описание компании | «Стоматология „Смайл“ в Киеве, 12 лет, 3 филиала...» |
| Инструкции | «Записывай на консультацию через оператора; не давай медицинских диагнозов» |
| Если не знает ответ | Передать оператору |
| Правила передачи | чекбоксы: попросил человек / не знает / жалоба (DOC-014) |

Загружайте то, что должна знать ниша: услуги, цены, врачи/расписание — для клиники; товары, доставка, возврат — для магазина.

## 5. Тестирование бота

- **Тестовый диалог** в админке (песочница): задайте типовые вопросы до публикации виджета; проверьте цитаты и поведение «не знает ответ».
- Проверьте сценарий «позовите оператора»: диалог появляется в очереди (попросите коллегу принять).
- Аналитика (Проект → Dashboard): доля handoff, вопросы с низкой релевантностью — что добавить в знания.

## 6. Команда

- Установка → Команда: администраторы установки.
- Проект → Участники: добавьте операторов (email + пароль), роль `operator` (или `project_admin` для полного доступа к проекту).
- Оператор видит только диалоги проектов, в которых состоит (DOC-015).

## 7. Настройки установки

| Блок | Зачем |
|---|---|
| AI-провайдер | ключи/модели (раздел 3) |
| SMTP | email-уведомления операторам (без SMTP работает только панель) |
| Бэкапы | расписание, retention, S3; кнопки «создать/скачать сейчас» |
| Телеметрия | opt-in отчёты об ошибках (по умолчанию выключено) |
| Обновления | проверить наличие версии; процедура — DOC-020 |

## Частые вопросы администратора

- **«Виджет пишет INVALID_ORIGIN»** — домен сайта не добавлен в allowed origins (раздел 2).
- **«AI отвечает не по документу»** — проверьте статус документа (ready?), актуальность версии; переиндексируйте.
- **«Оператор не получает email»** — не настроен SMTP.
- **«Хочу сменить провайдера»** — Настройки → AI-провайдер; ключи старого больше не нужны.

## Чек-лист запуска нового проекта

- [ ] Проект и сайт созданы; origins заполнены.
- [ ] AI-провайдер проверен; модели выбраны.
- [ ] Знания загружены, статусы ready.
- [ ] Ассистент настроен (тон, инструкции, правила передачи).
- [ ] Тестовый диалог пройден; сниппет передён на сайт (DOC-024).
- [ ] Операторы добавлены; уведомления проверены.
