# Глоссарий

## Краткое содержание

Термины по алфавиту. Обновлять при введении новых терминов (правила — DOC-029).

## Термины

| Термин | Определение |
|---|---|
| **ADR** | Architecture Decision Record — запись о архитектурном решении с альтернативами (DOC-026) |
| **ASSUMPTION** | Допущение, принятое до ответа заказчика; помечается в тексте (DOC-002) |
| **BYOK** | Bring Your Own Key — AI-провайдер используется на ключах заказчика |
| **Chunk (чанк)** | Фрагмент документа ~300–700 токенов с метаданными; единица поиска в RAG |
| **Conversation Engine** | Сервис оркестрации AI-хода: валидация → персистентность → retrieval → LLM → эскалация (DOC-005) |
| **Embedding** | Векторное представление текста (1536 измерений); модель фиксируется в чанке |
| **Escalation (эскалация)** | Передача диалога от AI оператору по правилам или просьбе (DOC-014) |
| **Handoff** | Запись о факте передачи диалога оператору (reason, rule_id, status) |
| **HNSW** | Алгоритм индексации pgvector для быстрого приближённого поиска ближайших векторов |
| **Installation (установка)** | Один развёрнутый экземпляр системы на сервере заказчика |
| **Integration Contract** | Три публичных контракта ядра (widget.js, /widget/v1, /api/v1+webhooks), через которые платформы подключаются без правки ядра (DOC-003 §5) |
| **Кэтч-ап (after_seq)** | Добор пропущенных сообщений после reconnect по монотонному seq |
| **Modular monolith** | Монолит с жёстко разделёнными модулями; без микросервисов (ADR-001) |
| **Ollama** | Локальный runtime LLM с OpenAI-совместимым API; режим «данные не покидают сервер» |
| **OpenAI-compatible** | HTTP-контракт чата/эмбеддингов, общий для десятков провайдеров (ADR-005) |
| **Operator (оператор)** | Роль пользователя: работа с диалогами в inbox проекта |
| **pgvector** | Расширение PostgreSQL для векторного поиска внутри основной БД (ADR-002) |
| **Project (проект)** | Изолированное пространство установки: сайты, ассистент, знания, операторы |
| **Prompt injection** | Атака инструкциями, спрятанными в документах/сообщениях (DOC-011 §6) |
| **Publishable key** | Публичный ключ сайта (`pk_live_...`); не секрет; полномочия ограничены виджетом |
| **RRF** | Reciprocal Rank Fusion — слияние векторного и полнотекстового ранжирования |
| **Retrieval-гейт** | Отказ от вызова LLM при релевантности KB ниже порога; главный барьер галлюцинациям |
| **Reranker** | Переупорядочиватель найденных чанков (кросс-энкодер); RRF — в MVP, кросс-энкодер — V2 |
| **RulesEngine** | Детерминированный движок правил эскалации по сигналам LLM (ADR-011) |
| **seq** | Монотонный номер сообщения в диалоге; гарантия порядка и кэтч-апа |
| **Shadow DOM** | Инкапсуляция DOM/CSS внутри custom element; изоляция виджета от сайта (ADR-004) |
| **Site (сайт)** | Подключённый к проекту домен: origins, publishable key, widget_config |
| **Structured output** | Ответ LLM строгой JSON-схемой, валидируемой сервером |
| **TBD** | To Be Determined — деталь не определена; требует решения |
| **Visitor (посетитель)** | Анонимный посетитель сайта (anon_id в localStorage + visitor JWT) |
| **Visitor token** | Подписанный JWT посетителя (24 ч); полномочия — только свои диалоги своего сайта |
| **Widget config** | Конфигурация виджета сайта: тема, тексты, custom_css (jsonb в `sites`) |
| **worker** | Процесс того же образа, что api: очереди, парсинг, эмбеддинги, бэкапы (ADR-010) |
| **Визард первого запуска** | Web-инструкция после установки: админ → проект → сайт → AI → знания (DOC-022 §1) |
| **Переиндексация** | Перестройка чанков документа: version+1 → фон → атомарный swap |
| **Синий/зелёный деплой** | Не используется; откат версий — DOC-020 |
