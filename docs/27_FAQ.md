# Частые вопросы (FAQ)

## Краткое содержание

Вопросы сгруппированы: общие, установка, AI, операторы, кастомизация. Каждый ответ — со ссылкой на раздел с деталями.

## Общие

**— Это SaaS? Где живут данные?**
Нет. Система ставится на сервер заказчика (VPS + Docker); все диалоги, знания и настройки — в PostgreSQL на этом сервере. Внешняя runtime-зависимость одна — AI-провайдер, и он заменяем, вплоть до полностью локального (Ollama). → DOC-001, DOC-003.

**— Обязательно нужен VPS? Мой сайт на shared hosting.**
Backend — да, VPS (Docker). Сам сайт может оставаться где угодно, включая shared hosting: виджет подключается одним `<script>`. → DOC-016, DOC-010.

**— Что будет, если сервер разработчика продукта станет недоступен?**
Установленная система продолжит работать: обновления и образы нужны только при установке/обновлении; принудительного phone-home нет. → DOC-003 §10.

## Установка и интеграция

**— Сколько занимает установка?**
Backend: ≤ 30 минут по шагам DOC-016. Виджет на сайт: ≤ 5 минут (сниппет или WP-плагин). → DOC-024.

**— Можно ли обслуживать несколько сайтов?**
Да: одна установка → проекты → сайты; у каждого свои знания, ассистент, операторы. → DOC-022 §2.

**— Виджет заблокируется адблоком?**
Скрипт отдаётся с собственного домена заказчика — в стандартные блок-листы не попадает. → DOC-010 §5.

## AI

**— Привязаны ли мы к OpenAI?**
Нет. Любой OpenAI-совместимый endpoint, включая локальный Ollama; смена — в настройках. → DOC-011.

**— Кто платит за AI?**
Заказчик — своим ключом провайдера (BYOK). Локальный LLM — без оплаты за токены. → DOC-011 §2.

**— AI может выдумывать?**
Guardrails: retrieval-гейт (без релевантных знаний LLM не вызывается), «отвечай только по контексту», цитаты источников, confidence с эскалацией. → DOC-011 §5.

**— Как обучить AI под мою нишу?**
Загрузить документы/FAQ/URL в базу знаний и настроить ассистента (тон, инструкции) — без программирования. → DOC-022 §4.

**— Сколько знает система? Куда деваются вопросы без ответа?**
Аналитика показывает вопросы с низкой релевантностью и топ причин эскалаций — что добавить в знания. → DOC-022 §5.

## Операторы

**— AI заменяет операторов?**
AI закрывает типовые вопросы; сложные — передаёт оператору по правилам или просьбе. Оператор может вернуть чат AI. → DOC-013, DOC-014.

**— Что если операторов нет онлайн?**
AI предложит оставить email — заявка сохранится и попадёт в уведомление. → DOC-013 §4.

## Кастомизация

**— Можно изменить дизайн чата под мой сайт?**
Да, вручную, тремя уровнями: конструктор в админке; CSS-переменные/свой CSS для верстальщика; полностью свой UI на публичном API. Автоподхвата дизайна нет — намеренно. → DOC-008 §4.

**— Поддерживаются ли языки, кроме русского/английского?**
Виджет и тексты — ru/en в MVP; расширение — V2 (TBD, DOC-002 Q-3).

**— Можно ли выгрузить историю диалогов?**
Экспорт диалога — функция админки (MVP); массовый экспорт/retention — V2. → DOC-015 §6.
